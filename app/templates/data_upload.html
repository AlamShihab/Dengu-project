Bring the data up to date: fetch the latest DGHS reports automatically, or upload DGHS daily PDFs / a CSV or Excel table yourself

Get the latest DGHS data

Downloads any new DGHS Daily Dengue Press Release PDFs (district table) and the DGHS dashboard's division and national figures up to today, then rebuilds the data. The deployed models then forecast Day 1-7 from the newest day. Needs the internet.

Accepted uploads (max {{ max_mb }} MB):
  • DGHS daily PDF (e.g. 20261012_dengue_all.pdf): the district table is read automatically, exactly as in the pipeline.
  • CSV / Excel table with columns report_date (YYYY-MM-DD), unit_code or district / division (English name or code, e.g. Faridpur or BD3029; Dhaka Metro; Bangladesh) and admitted_24h (new admissions in the last 24 hours).
Uploading only checks the file; adding it and re-running is a separate, confirmed step. Existing DGHS PDF data is never overwritten.
